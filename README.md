# Petruk-db-project

Информационная система аптеки предназначена для учета лекарственных препаратов, их характеристик и наличия, а также для хранения сведений о поставщиках, продажах и клиентах. Система должна обеспечивать удобное хранение и обработку данных, контроль ассортимента и получение необходимой информации о товарах и операциях аптеки.
